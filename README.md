## Selected projects

- **[uv_upgrade](https://github.com/Alirex/uv_upgrade)**: upgrades dependency versions in the
  `pyproject.toml` files of uv projects. On PyPI as [`uv-upx`](https://pypi.org/project/uv-upx/).
- **[rust_crate_to_workspace](https://github.com/Alirex/rust_crate_to_workspace)**: a Bash script that
  turns a single Rust crate into a Cargo workspace.
- **[path_as_uri](https://github.com/Alirex/rs_lib_i_path_as_uri)**: a Rust crate that turns a file path
  into a URI you can click in the terminal. On [crates.io](https://crates.io/crates/path_as_uri).
- **[app_root_folder](https://github.com/Alirex/rs_lib_i_app_root_folder)**: a Rust crate that finds the
  app's root folder, like `BASE_DIR` in Python projects. On [crates.io](https://crates.io/crates/app_root_folder).
- **[pre-commit-just](https://github.com/Alirex/pre-commit-just)**: a pre-commit hook that formats
  justfiles with `just --fmt` (my fork, with my own changes).
- **[ollama_docker_public](https://github.com/Alirex/ollama_docker_public)**: Ollama in Docker with GPU
  support, for running LLMs on your own server.
- **[notes](https://github.com/Alirex/notes)**: my notes on dependencies, IDE settings in a repo,
  linters and pre-commit (in Ukrainian and English).
